# Singing Reed Wind Toy

This is a little toy I'm building, one step at a time. A row of reeds stands by the water and sways in the wind.

Now (step 2) there is a wind slider at the bottom. Drag it right and the reeds lean and sway harder and faster. Drag it left and they settle down to a gentle nod.

Next I'll give each reed a soft hum, make the wind change the volume, and add colours that shift with the breeze.
